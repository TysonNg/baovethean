# Nginx Reverse Proxy and SSL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add reproducible VPS configuration for PM2-managed Next.js behind Nginx with Let’s Encrypt SSL for `baovethean.com` and a canonical redirect from `www`.

**Architecture:** PM2 runs the production Next.js server on loopback port 3000. Nginx owns ports 80/443, terminates TLS, redirects HTTP and `www`, and forwards canonical HTTPS traffic to Next.js. A bootstrap HTTP virtual host permits first-time certificate issuance before the final TLS configuration is installed.

**Tech Stack:** Next.js 16, Node.js, PM2, Nginx, Certbot, Let’s Encrypt, Ubuntu systemd

## Global Constraints

- Canonical URL is exactly `https://baovethean.com`.
- `www.baovethean.com` redirects permanently while preserving path and query.
- Next.js binds to `127.0.0.1:3000`; PostgreSQL is not exposed through Nginx.
- Payload uploads allow request bodies up to 50 MB.
- Existing user changes in the working tree must remain untouched.
